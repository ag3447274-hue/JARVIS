# JARVIS

My personal AI assistant.

## Goal

Build an advanced personal AI assistant that can:

- Understand voice and Hinglish
- Recognize authorized users by voice and face
- Remember useful information with permission
- Control permitted PC functions
- Connect with mobile services
- Use the internet and APIs
- Automate tasks
- Create, test and improve software projects
- Schedule tasks
- Have a useful and fun personality

## Vision

JARVIS will be developed step by step:

Foundation → AI → Voice → Vision → Memory → Tools → PC → Mobile → Automation → Advanced AI
